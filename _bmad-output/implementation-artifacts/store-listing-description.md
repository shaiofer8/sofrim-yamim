# תיאור לחנות Play Store

## Short description (עד 80 תווים)
```
ספירה לאחור לחגים ומועדים אישיים — עברית מלאה
```

## Full description (עד 4000 תווים)
```
סופרים ימים — ספירה לאחור פשוטה ויפה לחגים, ימי הולדת, אירועים אישיים וכל מה שאתם מחכים לו.

⏳ מה האפליקציה עושה
מוסיפים אירוע, בוחרים תאריך ואייקון — והאפליקציה סופרת בשבילכם את הימים שנשארו. פשוט, נקי, בלי הסחות דעת.

📅 חגים ומועדים ישראליים מובנים
כל החגים היהודיים והישראליים כבר בפנים — ראש השנה, יום כיפור, סוכות, חנוכה, פורים, פסח, יום העצמאות ועוד — לא צריך להזין תאריכים בעצמכם.

🔔 תזכורות
תזכורת יום לפני כל אירוע, כדי שלא תפספסו כלום.

🌓 מצב בהיר וכהה
מתאים אוטומטית להעדפת המכשיר שלכם.

🔒 הפרטיות שלכם נשארת שלכם
כל הנתונים שלכם נשארים על המכשיר בלבד — אין שרת, אין חשבון, אין איסוף מידע אישי.

בלי הרשמה, בלי סיבוכים — רק אתם, האירועים שלכם, והספירה לאחור.
```
